Chanlog 05:22:54  22.11.2026 Su:
Version 1.10
  Added:
  - Interface in English and Russian. Language is chosen automatically (Russian if Windows UI language is Russian, otherwise English); manual switch in Settings, saved in crocaun.ini (Lang=auto|ru|en), applied after restart.
  - Launch parameter -w / --workdir <folder>: all working files and folders (crocaun.ini, chat folder, Share, received, logs) live in that folder; several profiles from one exe. %VAR% is expanded. Documented in README.
  - Warning window at startup if the ports the program needs are busy (UDP 29008, TCP 29009-29013, chat TCP 29014 / UDP 29015). Real solution for port conflicts is in TODO.md.
  - Chat: participants pane to the right of every chat; "Check status" button (no background polling) and "Remove old" button.
  - Chat folder name can be changed in Settings; an existing folder (including legacy crocau-chat) is renamed automatically; if both old and new folders exist, the newer file (by modification time) wins on name clashes.
  - changelog.txt, README-EN.md, TODO.md.
  Changed:
  - Chat folder is now named crocaun-chat by default and is created only when the chat is enabled.
  - Version 1.10.
